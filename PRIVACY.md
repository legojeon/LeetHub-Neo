# Privacy Policy

Last updated: May 22, 2026

LeetHub-Neo is a Chrome extension that syncs accepted LeetCode submissions to a
GitHub repository selected by the user and provides study tools such as notes,
translations, topic organization, templates, and progress tracking.

This privacy policy explains what data LeetHub-Neo handles and how that data is
used.

## Data LeetHub-Neo Handles

LeetHub-Neo may handle the following data to provide its user-facing features:

- GitHub username, selected repository name, and GitHub OAuth access token.
- LeetCode username and LeetCode site selection, such as leetcode.com or
  leetcode.cn.
- Accepted LeetCode submission code, submission metadata, problem titles,
  problem slugs, difficulty, topic tags, problem descriptions, and problem URLs.
- User-created content such as scratchpad notes, topic notes, custom commit
  messages, and solution-related notes.
- Extension settings such as folder organization preferences, template
  language, translation language, and sync options.
- Progress information such as solved counts, difficulty distribution, recent
  activity, streaks, and top tags.
- Cached translated problem descriptions when the translation feature is used.

LeetHub-Neo does not collect health information, financial or payment
information, location information, or personal communications.

## How Data Is Used

LeetHub-Neo uses data only to provide the extension's core features:

- Authenticating GitHub API requests authorized by the user.
- Creating, reading, updating, and organizing files in the user's selected
  GitHub repository.
- Syncing accepted LeetCode submissions and related problem metadata.
- Displaying the side panel, scratchpad, topic workspace, templates, repository
  settings, and progress dashboard.
- Translating problem descriptions with Chrome's built-in Translator API when
  supported by the user's browser and selected by the user.
- Caching extension settings, progress data, and translated descriptions locally
  so the extension can work reliably over time.

LeetHub-Neo does not sell user data, use user data for advertising, or use user
data for unrelated analytics or profiling.

## Data Storage

LeetHub-Neo stores extension data in the user's browser using Chrome extension
storage. This includes the GitHub OAuth token, selected repository, settings,
progress data, notes-related preferences, and cached translations.

When the user chooses to sync data to GitHub, LeetHub-Neo sends the relevant
submission code, notes, topic files, templates, metadata, and repository summary
files to the GitHub repository selected by the user.

## Data Sharing

LeetHub-Neo shares data only as needed to provide the features requested by the
user:

- GitHub receives authenticated API requests so LeetHub-Neo can create, read,
  and update files in the user's selected repository.
- LeetCode receives requests needed to read problem, account, submission, and
  problem metadata from the LeetCode pages and APIs the user is using.
- Chrome's built-in Translator API may process problem description text locally
  or through Chrome-managed functionality depending on Chrome's implementation
  and availability for the user's browser profile.

LeetHub-Neo does not send user data to a custom LeetHub-Neo server.

## Security

LeetHub-Neo uses HTTPS requests when communicating with GitHub and LeetCode.
GitHub OAuth tokens are stored in Chrome extension storage on the user's device
and are used only for GitHub API requests required by the extension's sync and
repository-management features.

Users should only connect repositories they intend LeetHub-Neo to manage.

## User Control and Data Deletion

Users can stop using LeetHub-Neo at any time by disconnecting or uninstalling
the extension from Chrome.

Users can delete locally stored extension data by removing the extension or by
clearing the extension's site and storage data in Chrome. Users can also remove
or edit files that LeetHub-Neo created in their GitHub repository directly from
GitHub.

To revoke GitHub access, users can remove LeetHub-Neo from their authorized
GitHub OAuth applications in GitHub account settings.

## Remote Code

LeetHub-Neo does not execute remotely hosted JavaScript. Extension scripts and
third-party libraries are bundled with the extension package.

## Limited Use

LeetHub-Neo uses user data only for user-facing extension features that are
described in the Chrome Web Store listing and in the extension interface. User
data is not sold, transferred for advertising, or used for purposes unrelated to
GitHub synchronization, LeetCode study organization, notes, translations,
templates, and progress tracking.
